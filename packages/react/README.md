# @instaconnect/react

Accessible React components and headless hooks for displaying Instagram feeds, Reels, carousels, and profile headers.

## Components
- `<InstagramFeed />`
- `<InstagramGrid />`
- `<InstagramReels />`
- `<InstagramProfile />`
- `<InstagramConnectButton />`

## Hooks
- `useInstagramFeed()`
- `useInstagramReels()`
- `useInstagramProfile()`
- `useInstagramMedia()`
- `useInstagramConnection()`
